# Streamer Console Spec v2

## 1. 目标

Streamer Console 是后续的主播运营控制台，不是首发主入口。

首发阶段主播主要通过 `game-client` 直播和看世界，等核心闭环跑通后，再补完整控制台。

## 2. 首发不依赖

```text
订阅管理
世界列表管理
完整礼物配置台
复杂权限系统
团队协作
```

## 3. 后续功能

```text
登录
查看世界
创建直播会话
连接礼物来源
复制用户创建链接
查看 NPC 危机榜
查看最近礼物事件
切换直播镜头
查看订阅状态
```

## 4. MVP 原则

```text
先把 game-client + viewer + backend 跑通。
控制台只在确有需要时补。
```
