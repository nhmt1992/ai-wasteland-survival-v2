# Product Strategy v2

## 1. 产品定位

AI Wasteland Survival v2 是面向 TikTok 主播的 AI-NPC 生存直播互动 SaaS。

平台不直接依赖观众付费，而是向主播提供可提升直播互动和礼物收入的游戏工具。

```text
主播付费使用平台。
主播用自己的 TikTok 账号直播。
观众创建 AI-NPC 并通过礼物支援。
主播获得礼物收益。
平台获得主播订阅收入。
```

## 2. 核心客户

直接客户是主播，不是普通观众。

| 客户 | 需求 |
|---|---|
| TikTok 小主播 | 提升直播间互动，制造话题 |
| TikTok 中型主播 | 用固定活动提高粉丝留存和礼物收入 |
| 直播公会 / 团队 | 给多个主播配置可复用互动内容 |
| 平台运营者 | 通过 SaaS 套餐获得稳定收入 |

## 3. 核心价值

对主播：

```text
低成本获得一个可直播互动的 AI 沙盒世界。
观众可以拥有自己的 NPC。
礼物支援能直接影响直播画面。
主播可以围绕 NPC 生死、部落、冲突讲故事。
```

对观众：

```text
自己的 TikTok ID 绑定一个 AI-NPC。
NPC 会在主播世界里自主生存。
礼物能支援自己的 NPC，但不能直接控制。
NPC 会产生记忆、关系、死亡和遗产。
```

对平台：

```text
向主播收月费。
提供多租户服务端、直播端、用户端、Overlay、Tick Engine。
后续通过套餐限制和增值功能扩大收入。
```

## 4. 商业模式

### 4.1 主收入

```text
主播月费订阅
```

套餐方向：

| 套餐 | 目标主播 | 限制 |
|---|---|---|
| Free Trial | 体验用户 | 7 天，最多 5 NPC，有水印 |
| Starter | 小主播 | 1 世界，20 NPC，基础 Overlay |
| Pro | 正式主播 | 3 世界，100 NPC，高级礼物映射 |
| Studio | 团队 / 公会 | 多世界，多主播账号，品牌定制 |

### 4.2 增值收入

```text
更多 NPC 容量
更多世界数量
自定义 Overlay 皮肤
主播品牌 Logo
高级数据分析
AI 事件旁白额度
长期世界存档
活动模板
部落赛季活动
```

## 5. 游戏循环

```text
主播开播
→ 观众通过主播链接创建 NPC
→ NPC 进入主播专属世界
→ NPC 自主生存、结盟、争夺资源
→ 世界制造危机
→ 主播讲述危机
→ 观众刷礼物支援
→ 礼物通过主播直播间进入对应世界
→ NPC 获得资源但仍自主判断
→ 形成新的直播故事
```

## 6. 平台收益闭环

```text
游戏提高主播直播互动
→ 主播获得更多礼物和粉丝停留
→ 主播愿意支付月费
→ 平台获得稳定订阅收入
→ 平台继续增强世界、AI、Overlay、数据分析
```

## 7. 产品边界

### 平台负责

```text
账号系统
主播订阅
世界运行
NPC AI
礼物事件标准化
Overlay
用户创建链接
用户观看端
数据存储
权限隔离
```

### 主播负责

```text
自己的 TikTok 直播账号
直播内容表达
引导观众创建 NPC
引导观众礼物支援
```

### 观众负责

```text
创建 NPC
观看 NPC
通过礼物支援 NPC
```

## 8. MVP 成功标准

```text
一个主播能登录。
一个主播能拥有自己的世界。
主播能打开 OBS Overlay。
观众能通过主播链接创建 NPC。
模拟礼物能进入该主播世界。
5 个 NPC 能运行 1 小时。
主播能围绕 NPC 事件讲故事。
```

## 9. 暂不做

```text
所有主播共享大世界。
复杂分账。
真实 TikTok 官方深度集成。
公会多账号权限。
完整数据分析系统。
移动 App。
```
