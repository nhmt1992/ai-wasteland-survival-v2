# Art Direction

## 目标

v2 的直播画面不是复古像素展示，而是面向主播直播间的高可读性荒土视觉系统。

核心方向：

```text
荒土末日 × 2.5D 等距 × 高清像素风 × 直播强化 UI
```

优先级顺序：

```text
1. 直播可读性
2. 危机表达
3. NPC 个体识别
4. 礼物反馈冲击
5. 世界荒凉感
```

## 视觉原则

- 观众 1 秒内能看懂谁在危险、谁收到礼物、哪里发生了事件。
- NPC 必须有清晰名字牌、状态条和轮廓差异。
- 礼物必须有明显演出，不只是数值变化。
- 死亡和濒死必须是红色信号，不可弱化。
- 世界要像可讲述的地点，而不是纯地板贴图。

## 颜色基调

主色建议：

```text
背景：#120f0b
面板：#1a140f / rgba(18, 12, 8, 0.92)
边线：#c88e36 / rgba(255, 198, 87, 0.45)
文本：#f5e8d0
弱文本：#a89a81
强调金：#e2b04d
危险红：#ef675d
水蓝：#7dc0ef
安全绿：#86c86b
```

原则：

- 不把背景往冷蓝或紫色方向带。
- 不把地表做成单一棕色块。
- 语义色只用于信息反馈，不做纯装饰。

## 文字与层级

- 主标题大、短、硬，适合 OBS 远看。
- NPC 名字牌要比普通面板文本更大。
- 状态条数字必须能在压缩后读清。
- 日本语 UI 文案优先使用简短词，不堆解释句。

## 画面构成

推荐层级：

```text
background
tile
object
npc
effect
nameplate
hud
alert
```

## 参考基准

当前阶段参考图应满足：

- OBS 主画面完整效果
- 局部地图细节
- NPC + HUD 细节

这些图只用于建立视觉基线，不代表最终生产素材。

## 不要做

- 不要做现代科幻 UI。
- 不要做营销页风格的漂浮卡片。
- 不要做低对比度的装饰性背景。
- 不要让礼物效果变成纯数值提示。
- 不要把 NPC 做成没有辨识度的统一小人。
